# 混合路线（C+）：代码动画为主，AI 只出插图窗

适合讲规则或流程的宣传片：文字、数字、进度条必须零出错，又想要几个生活场景画面。

1. 主体用 Remotion 画（规则、数字、卡片文字、进度条都是代码，不会被 AI 画错）。AI 只出**插图窗里的场景**；用 `brief.py lock ... --palette-en` 指定项目色盘，色盘会覆盖预设，lint 不会报“漂移”。
2. 引擎只管那几个 AI 镜头。manifest 的 `timeline` 里写 `"coverage": "partial"`，告诉 lint 这些镜头只是插入件，不用铺满整条时间线（镜头重叠仍然报错）。
3. 顺序：`lint.py` → `pipeline.py estimate <slug> --fast` → `stills.py <slug> L2` → 看图，必要时人工改选 → `pipeline.py upgrade <slug> --fast` → 审片 → `pipeline.py review` → 把剪好的片段放进你的 Remotion 工程 → 渲染 → `deliver.py`。
4. **快速档 `--fast`**：960×544、81 帧、16 步，实测 3.3–3.7 分钟一条。插图窗只有约 400 像素宽，这档够用。
5. 片中的规则、数字、卡片文字**必须从产品的真实数据读**，不凭印象写；读不到的就不写。
6. 插图窗里的 AI 场景只是示意，对外使用要注明“画面为示意”。
7. 时间线先算再画：每个环节的起止秒写成常量，渲染前先算有没有重叠。预览用 `--scale=0.5`（30 秒的片子约 30 秒渲完）。
